# SpaceLayouts

Menueleisten-App fuer macOS 14 und neuer: Jeder native Schreibtisch (Space) bekommt sein eigenes Fensterlayout.

- Layouts pro Schreibtisch und Display (Halbe, Drittel, Viertel, Stapel, Haupt + Seite, Staged, Scroll-Layout im niri-Stil)
- Eigene Leiste pro Display mit Fenster-Vorschau, Panes mit Tab-Gruppen, Drop-Zonen, verschiebbare Teiler
- Option-Tab-Switcher mit Suche, einstellbarer Fokusrahmen

## Download

Die aktuelle Version liegt unter [Releases](../../releases). Die App ist mit Developer ID signiert und von Apple notarisiert.

1. `SpaceLayouts-<Version>.zip` laden und entpacken.
2. `SpaceLayouts.app` in den Ordner Programme ziehen und starten.
3. Beim ersten Start die Freigaben fuer Bedienungshilfen (Fenster verschieben) und Bildschirmaufnahme (Fenster-Vorschau) erteilen.

## Hinweise

- Universal (Apple Silicon und Intel).
- Nutzt interne macOS-Funktionen (SkyLight); daher nicht im App Store erhaeltlich. Einzelne Funktionen koennen nach macOS-Updates eine Anpassung brauchen.
- Dieses Repository enthaelt nur die Releases, keinen Quellcode.
